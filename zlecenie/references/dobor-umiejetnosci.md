# Które umiejętności wpisać do polecenia

Wpisujesz najwyżej trzy: tę, która rządzi pierwszym krokiem, tę dziedzinową i tę, która sprawdza wynik.
Każdą nazwę sprawdzasz na liście umiejętności dostępnej w tej rozmowie i przepisujesz dosłownie. Gdy nazwy
nie ma na liście, nie wpisujesz jej.

W poleceniu piszesz zdaniem, kiedy umiejętność ma zadziałać: „Najpierw wywołaj umiejętność
superpowers:brainstorming”, „Przed zdaniem »zrobione« użyj superpowers:verification-before-completion”.

Tabele poniżej zawierają tylko umiejętności z wtyczki superpowers i umiejętności Anthropic. Dopisz do nich
własne: w tabeli „Sposób pracy” te, które sprawdzają jakość albo zbierają wiedzę, a w tabeli „Dziedzina”
te, które znają Twoje projekty i narzędzia.

## Sposób pracy

| Sytuacja | Umiejętność |
| --- | --- |
| Coś do zbudowania, a kształt jest niejasny | `superpowers:brainstorming` |
| Jest cel i wymagania, potrzebny plan kroków | `superpowers:writing-plans` |
| Dwa lub więcej zadań niezależnych od siebie | `superpowers:dispatching-parallel-agents` |
| Plan z kolejnymi krokami, wykonanie przez pomocników w jednej rozmowie | `superpowers:subagent-driven-development` |
| Plan wykonuje sama rozmowa, bez pomocników | `superpowers:executing-plans` |
| Błąd, awaria, coś działa inaczej niż powinno | `superpowers:systematic-debugging` |
| Zmiana zachowania w kodzie | `superpowers:test-driven-development` |
| Przed zdaniem „zrobione” | `superpowers:verification-before-completion` |
| Przegląd zmiany przed scaleniem | `superpowers:requesting-code-review` |
| Dopisz własne: decyzja i kierunek, kontrola jakości materiału, zbieranie wiedzy, przekazanie rozmowy | … |

## Dziedzina

| Zadanie | Umiejętność |
| --- | --- |
| Budowa albo przebudowa wyglądu strony, panelu | `frontend-design:frontend-design` |
| Wykres, panel z danymi | `dataviz` |
| Dokument Word, arkusz, prezentacja, PDF | `docx`, `xlsx`, `pptx`, `pdf` |
| Nowa albo poprawiana umiejętność | `skill-creator:skill-creator` |
| Dopisz własne: Twoje dziedziny, narzędzia i projekty | … |

## Czego nie wpisujesz

- `superpowers:using-superpowers` — ładuje się sama na starcie każdej rozmowy.
- Kilku umiejętności, które robią to samo (na przykład dwóch różnych kontroli jakości tego samego
  materiału).
- Umiejętności „dla pewności”. Każda wczytana umiejętność zajmuje miejsce w rozmowie i odciąga uwagę
  od zadania.
